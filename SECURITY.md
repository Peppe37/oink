# Security

Oink handles personal financial data, so security reports are welcome and taken seriously.

**Please do not open a public issue.** Use GitHub's *Report a vulnerability* (Security tab),
and give enough detail to reproduce it. You'll get an answer within a few days.

Supported: the latest release. Self-hosters should keep `./data` private, put Oink behind HTTPS
if it is reachable from outside, change the admin password at first sign-in and update
regularly (`docs/self-hosting.md`).
